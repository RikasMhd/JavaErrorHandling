# JavaErrorHandling
Error handling in Java means handling runtime errors (exceptions) so that the program does not crash suddenly and can respond properly.simply we say Error handling in Java prevents program crashes and ensures smooth execution by handling runtime errors properly.It helps in showing proper error messages, keeps the program running normally, and ensures resources like files are closed using "finally".This makes programs more reliable, safe, and user-friendly.

Java uses:
  i.try
  ii.catch
  iii.finally
  iv.throw / throws
to handle errors.
